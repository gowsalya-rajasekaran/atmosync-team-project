Superset Virtual Dataset Definition (Snowflake SQL)

To eliminate the +66.6% cargo inflation caused by duplicate batch ingestion on 2026-11-15, configure the Superset physical/virtual dataset using Snowflake's QUALIFY ROW_NUMBER() window function: 

CREATE OR REPLACE VIEW ATMOSYNC_DB.PUBLIC.VW_SENSOR_TELEMETRY_CLEAN AS
SELECT
    EVENT_ID,
    EVENT_TIMESTAMP,
    CONTAINER_ID,
    TEMPERATURE,
    HUMIDITY,
    VIBRATION,
    COMMODITY,
    QUANTITY_KG,
    INGESTED_AT
FROM ATMOSYNC_DB.PUBLIC.SENSOR_TELEMETRY
QUALIFY ROW_NUMBER() OVER (
    PARTITION BY EVENT_ID 
    ORDER BY INGESTED_AT ASC
) = 1;
