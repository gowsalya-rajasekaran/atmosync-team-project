# AtmoSync – Snowflake Data Warehouse

## 1. Module Overview

This module focuses on setting up the Snowflake data warehouse for the AtmoSync project.

Snowflake will be used to store container sensor data generated by the IoT simulator and streamed through Apache Kafka.

## 2. Technologies Used

- Snowflake Cloud Data Warehouse
- SQL
- JSON
- Apache Kafka (integration pending)

## 3. Database and Schema Setup

**Database:** `ATMOSYNC_DB`

**Schema:** `RAW_DATA`

The database and schema have been successfully created and verified.

## 4. Tables Created

### CONTAINER_SENSOR_DATA

An initial structured sensor data table was created for practice using separate columns for sensor information.

The final table structure is subject to confirmation with the project team.

### CONTAINER_EVENTS_RAW

A practice raw JSON table was created with the following columns:

| Column | Data Type | Purpose |
|---|---|---|
| EVENT_ID | VARCHAR(100) | Identifies each event |
| RAW_PAYLOAD | VARIANT | Stores the complete JSON event |
| INGESTED_AT | TIMESTAMP_NTZ | Records the ingestion timestamp |

One sample JSON sensor event was successfully inserted and verified.

## 5. JSON Data Handling

Practised the following Snowflake SQL concepts:

- `PARSE_JSON()` – converts JSON text into VARIANT format.
- JSON field extraction using `:`.
- Data type conversion using `::VARCHAR` and `::FLOAT`.
- Inserting JSON data into a VARIANT column.
- Querying stored JSON records.
